# Säuren und Basen

Lern-App für die Unterstufe: pH-Skala mit Indikatorfarben zum Ausprobieren (Werkbank), Säuren und Laugen mit Dissoziation,
Neutralisation, Quiz über `@lern/quiz`. Fachlogik in `packages/chem/src/acids.ts`.

- `npm run dev -w apps/saeuren-basen` – Entwicklung
- `npm run build -w apps/saeuren-basen` – Web-Version (`dist/`) und Einzeldatei (`dist-single/`)
