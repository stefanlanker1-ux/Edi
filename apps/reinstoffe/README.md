# Reinstoffe und Gemische

Stoffe aus dem Regal in ein Becherglas geben und sehen, was entsteht – links das Becherglas, wie man es sieht
(Schichten, Bodensatz, trüb, milchig), rechts dasselbe im Teilchenmodell.

- **Einteilung:** Reinstoffe (Elemente, Verbindungen) und Gemische – homogen (Lösung, Legierung, Gasgemisch) oder heterogen
  (Emulsion, Suspension, Gemenge, Schaum, Rauch, Nebel), mit Aggregatzuständen; Zählung **Phasen / Elemente / Verbindungen**
- **Experimentieren:** 20 Reinstoffe, Schütteln/Absetzen, **Trennen** (Magnet, Filtrieren, Dekantieren, Scheidetrichter, Eindampfen,
  Destillieren – mit Begründung, wenn es nicht passt), **Erhitzen** (Eisen + Schwefel → Eisensulfid, Metalle → Legierung, Zucker verkohlt)
- **Quiz:** Reinstoff oder Gemisch, Element oder Verbindung, homogen/heterogen, Gemischtyp, Aggregatzustände, Teilchenbilder auszählen,
  Trennverfahren, Erhitzen – mit diagnostischen Distraktoren (Stolpersteine), Erklärkarten und Wiederholung

## Entwickeln
```bash
npm install              # im Hauptordner
npm run dev:reinstoffe      # http://localhost:5173
```
