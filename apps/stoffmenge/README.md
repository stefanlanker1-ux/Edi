# Stoffmenge

Lern-App für die Unterstufe: molare Masse aus dem PSE, n = m / M, Teilchenzahl und Gasvolumen – Werkbank zum Rechnen und Quiz über `@lern/quiz`.
Fachlogik in `packages/chem/src/moles.ts`.

- `npm run dev -w apps/stoffmenge` – Entwicklung
- `npm run build -w apps/stoffmenge` – Web-Version (`dist/`) und Einzeldatei (`dist-single/`)
